## The joke

> The office printer only jams on documents marked urgent, which is how I know it can read.

89 characters, one line, punchline on the final beat: the printer jams *selectively*, as if it could read.

## Run

```sh
node main.ts
```

Node 22+, standard library only, no dependencies. Writes the joke to `/output/entry.txt` with no trailing newline.
